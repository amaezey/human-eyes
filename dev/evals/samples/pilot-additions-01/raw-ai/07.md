Today we are releasing the May 2019 update to our browser, with improvements that make everyday browsing faster and more responsive.

The most noticeable change is quicker page loading. We have reduced the amount of work the browser performs before displaying a page and improved the way it handles commonly used web resources. In our testing, pages opened more quickly across a range of news, shopping and productivity sites, particularly on computers with several tabs already open. Actual results will vary by device, network and website, but the benefit should be apparent in normal use.

This release also uses memory more efficiently. Tabs that have been left in the background now place less pressure on the system, while the active tab receives the resources it needs sooner. This helps the browser remain responsive during longer sessions and reduces slowdowns when moving between several open pages. We have also addressed cases in which closing a tab did not immediately return memory to the system.

Starting the browser is faster, especially for people who restore tabs from a previous session. We changed the order in which restored content is loaded so that the browser window becomes usable sooner. Frequently visited pages are prioritised, while inactive tabs continue loading without holding up the rest of the session.

Under the hood, the update includes improvements to JavaScript execution, graphics rendering and network request scheduling. Together, these changes reduce delays in interactive web applications and produce smoother scrolling on complex pages. We fixed several performance regressions reported after earlier updates, including unnecessary processor use during video playback and lag when typing into some online editors.

The May 2019 release will roll out automatically over the coming days. You can check for it now by opening the browser menu, selecting Help, and choosing About. The update also includes security and stability fixes, so we recommend installing it when it becomes available.

Thank you to everyone who shared diagnostic data and reported performance problems. Your feedback helped us identify the areas where small delays added up, and it continues to guide our work on a faster browser.
